### 分档：六条轻档 + 一条重档

- **No.118 及之前的六条**：≤15s、主体动作 ≤2 拍、素材 0 份、台词 0 句 → 轻档。若成片主体崩坏或需要节拍控制，按 skill 纪律**升重档重写**，不要在轻档上加词续命。
- **No.129 对话条**：两人同框 + 台词两句，命中重档升级条件 → 2.5 版按基础公式写时间戳节拍（整数秒、覆盖全片、末景 = 总时长），2.0 版按官方「镜头序号优先、禁精细秒点」写四要素分镜；交付带可调项（见该节）。

### 2.5 与 2.0 的关系

**同一件作品的两版提示词 = 同一部片子的双模型写法**，创意与画面完全一致——它们填充的是同一个作品位，用哪个模型生成，进站的都是同一件作品。两版的差异只在各自模型的口径上：

- **2.5**：标准轻档预算（150–200 字符量级）。
- **2.0**：按官方口径收紧预算（更短）；「无 Logo」加入干净交付兜底（2.0 字幕/水印仍是顽疾）；唯一 人物镜头（No.118）按官方默认挂载补一句形体稳定兜底。
- fast / mini 档建议只做 4–5s 试片验证构图，成片换标准版出。

### 其他约定

- **任务类型**：参考生视频（本组无参考素材，即纯文生视频）。即梦网页版入口对应「全能参考」；方舟 API / 聚合平台直接发起视频生成任务。
- **分辨率**：统一 720p——站点视频走 `<video muted loop autoplay>` 静音循环，README 建议 ≤8MB，720p 足够。2.0 标准版支持 1080p/4K，追求更清晰可自行上调。
- **9:16 三条（No.126 / 122 / 118）**：2.0 竖屏出字幕概率偏高。若反复出现随机字幕，改出 16:9 横版再裁成 9:16（横屏字幕概率明显更低）。
- **声音**：站内播放静音，声音不影响交付，提示词未做声音约束；若素材另作他用，默认保留真实环境音。
- **干净交付是硬要求**（画廊公开展出）：每条末尾只挂一次「无字幕、无水印」，未堆其他禁止项。
- **假设说明**：主体、场景、氛围均按 `works.ts` 已有的 `title / pal / accent / prompt` 字段设计；原字段里的 `--dur --seed` 等是站点展示用的虚构参数，与生成无关，不要带进输入框。
